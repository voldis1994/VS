# VS — 3 faili (vairāk nevajag)

## 1) SERVER uz i3 (Debian)
```bash
sudo bash /root/VS/SERVER/1_START_I3
```

## 2) Komunikācija (USB / WireGuard conf)
```bash
sudo bash /root/VS/SERVER/2_EXPORT_USB
```
Ņem mapi `/home/vs/VS-USB/` vai USB: `VS-ADMIN-01.conf` + `ADMIN_TOKEN.txt`  
`Endpoint` jau ir **LAN IP** (ne VS-CORE-01).

## 3) ADMIN uz Windows
1. WireGuard → Import `VS-ADMIN-01.conf` → **Activate**
2. `ping 10.77.0.1`
3. Dubultklikšķis: `VS\ADMIN\1_START_WINDOWS.bat`

LIVE = off (DEMO).
