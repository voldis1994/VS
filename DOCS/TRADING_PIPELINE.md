# Trading pipeline

```
MARKET DATA → INDICATORS → REGIME → STRATEGY → SIGNAL → RISK → EXECUTION → BROKER GATEWAY → CAPITAL.COM
```

- Regime ≠ order  
- Strategy ≠ order  
- Signal ≠ order  
- Risk DENY cannot be UI-bypassed  
- LIVE trading defaults **false** (fail-closed)

See also: `REGIMES.md`, `STRATEGIES.md`, `RISK.md`, `EXECUTION.md`.
