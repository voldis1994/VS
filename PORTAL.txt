VS CLIENT PORTAL = Control API on i3
====================================

WRONG (do not do this):
  SSH to AWS/CentOS  (centos@ip-172-31-...)
  /home/centos/portal
  start-portal.sh + node server.js
  Error: Cannot find module 'express'

That box is NOT VS-CORE-01. Do not npm install express there.
VS does not use a separate Express portal on port 3000.

RIGHT:
  i3 Debian (same LAN as MSI) runs Control API :3000
  CLIENT/desktop is built INTO that API (static files)
  Browser: http://<i3-LAN-IP>:3000/
  Remote:  http://10.77.0.1:3000/  after WireGuard

I3:
  cd ~/VS-new/VS
  git pull origin main
  sudo bash FORCE_I3_LAN
  hostname -I
  curl -fsS http://127.0.0.1:3000/health
  # must show "service":"VS-CORE" and "server_id":"VS-CORE-01"

MSI (C:\VS-main only):
  cd /d C:\VS-main
  git pull origin main
  echo I3_LAN_IP> ADMIN\config\SERVER_IP.txt
  ADMIN\PHYSICAL_VERIFY.bat
  ADMIN\CONNECT_FORCE.bat
  Then ADMIN UI http://127.0.0.1:5188/
  CLIENTS → CREATE WEB LOGIN → customer opens http://I3_LAN_IP:3000/
