MSI — VIENA KOMANDA
===================

NEDRĪKSTI palaist no C:\Users\voldi

1) cd /d C:\VS-main
   dir START_MSI.bat

2) i3 IP (no i3 hostname -I), piemēram 192.168.0.10:
   mkdir ADMIN\config 2>nul
   echo 192.168.0.10> ADMIN\config\SERVER_IP.txt
   git pull origin main

3) Vispirms DIAGNOZE (nevis uzreiz START):
   ADMIN\PROVE_LAN.bat

   - ja ping FAIL = cita WiFi / Guest / AP isolation (NAV VS kļūda)
   - ja curl OK = tad START_MSI.bat

4) START_MSI.bat

Ja WiFi bloķē laptop↔laptop:
  - izslēdz router AP/client isolation
  - VAI ethernet
  - VAI WireGuard → tad ADMIN izmanto http://10.77.0.1:3000
