MSI STUCK?  (i3 /health already OK)
=================================

i3 ir gatavs. MSI neredz = WiFi ceļš, VAI nepareizs IP (piem. 192.168.8.10 kad i3 ir 192.168.0.10).

I3:
  cd ~/VS-new/VS
  git pull origin main
  sudo bash FORCE_I3_LAN
  hostname -I    ← reālais LAN IP

MSI (TIKAI no C:\VS-main — NE C:\VS-admin):
  cd /d C:\VS-main
  git pull origin main
  echo REAL_I3_IP> ADMIN\config\SERVER_IP.txt
  ADMIN\PHYSICAL_VERIFY.bat
  ADMIN\CONNECT_FORCE.bat

CONNECT_FORCE dara ping+curl+server_id. Ja identity FAIL:
  - SERVER_IP.txt ir nepareizs (cits subnet)
  - vai ne VS-CORE :3000 uz tā IP

Ja curl FAIL:
  - tā PATI WiFi kā i3 (ne Guest)
  - router: izslēdz AP/Client Isolation
  - VAI ethernet
  - VAI WireGuard → echo 10.77.0.1> ADMIN\config\SERVER_IP.txt
